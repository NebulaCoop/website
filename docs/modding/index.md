## About modding Nebula

These docs are Nebula's, by keepvaibin, with a [Co-op section](coop/index.md) added for NebulaCoop. They follow Nebula's newest modding (LumaKit, services and the new LumaLink), which reaches NebulaCoop with its update to Nebula 2; until then, some of it may not work in NebulaCoop yet.

A Nebula mod can change the game's content, patch its tables, and run code. You write code in LumaScript or C, build and pack the mod with LumaLink, and share it as a `.luma` file.
