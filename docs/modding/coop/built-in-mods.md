## The built-in mods

NebulaCoop comes with these mods. Their source is in [LumaLink Coop's `builtin` folder](https://github.com/NebulaCoop/lumalink-coop), and they make good examples of co-op mods.

| Mod | What it does |
|---|---|
| Personal Star Counter | sm64coopdx's mod: each player's Power Stars this room and all time. A LumaScript mod that uses the [`coop` calls and events](players-and-events.md). Off by default; the host turns it on in the room's mods. |
| Character Movesets | Luigi's own moves from Super Mario Galaxy, as a data-only mod: a layer's `player_constants` (see [Characters](characters.md)). Off by default, so every character plays like Mario. |
