NEBULA

Nebula, by keepvaibin

NebulaCoop is a fork of Nebula, the native PC port of Super Mario Galaxy, by keepvaibin. Everything that makes the game run on a PC is Nebula’s: the host, the renderers, Setup and the launcher, controller and Wii Remote support, mods, LumaScript and LumaLink, achievements and the settings menu. NebulaCoop follows Nebula closely and brings in its changes regularly.

This website started from Nebula’s own website: its pages, how it is built and its modding documentation. Its look and logo are NebulaCoop’s own.

Nebula’s website ↗ Nebula on GitHub ↗ Nebula’s Discord ↗
CO-OP

sm64coopdx and CoopNet

sm64coopdx and its CoopNet are the model for how co-op plays here: rooms and room codes, instances, player interaction, the bubble on death, chat commands, pop-ups, characters, palettes and the Personal Star Counter. Its design is followed; its code is not used.

sm64coopdx on GitHub ↗ CoopNet on GitHub ↗

NebulaCoop’s co-op is made by Mackery. NebulaNet, its room-code service, and LumaLink Coop are NebulaCoop projects too.
