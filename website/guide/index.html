REQUIREMENTS

System requirements

Setup prepares the game from your own copy. NebulaCoop includes no game files.

Requirement NebulaCoop
Operating system Windows 10 (1803 or newer) or Windows 11, 64-bit
Processor x86-64 with AVX2
Graphics Direct3D 12 (Vulkan is also offered)
Memory 8 GB RAM
Storage 8 GB free for setup
Your game Super Mario Galaxy for Wii, revision 0: North America (RMGE01), Europe (RMGP01) or Japan (RMGJ01). Super Mario Galaxy 2 is not supported.
Accepted formats ISO, RVZ or an extracted game folder

Everyone in a room needs a supported disc and the same NebulaCoop version. To play online you also need an internet connection.

INSTALL

Installation

  1. 01

    Download Setup

    Use the download page to get Nebula-Setup.exe, NebulaCoop’s Setup.

  2. 02

    Choose your game

    Run Nebula-Setup.exe and select your game. Setup checks the disc and its revision. If Nebula is already installed, Setup offers to import its game and saves.

  3. 03

    Install

    Choose Install. Setup prepares the game and adds NebulaCoop to the Start menu, beside Nebula if you have it.

  4. 04

    Play

    Open NebulaCoop from the Start menu. Set your name and character on the PLAYER page, then Host or Join.

Download NebulaCoop only from its GitHub releases. It isn’t code-signed yet: if Windows shows “Windows protected your PC”, choose More info, then Run anyway.

FIRST LAUNCH

First settings

Open Options from the main menu, or press F1 in the game. On controllers, press View + Menu (Xbox, Steam), Share + Options (PlayStation) or Minus + Plus (Switch).

  • On an older computer, start at a low internal resolution and raise it while the game stays smooth.
  • Set Aspect ratio to Auto, and HUD resolution to Display for sharp menus and text.
  • On a display faster than 60 Hz, turn on Interpolation and set the target frame rate.
  • Set your name, character and colours on the PLAYER page before you go online.
  • Choose Apply to keep changes, or Undo to discard them. Display changes revert after a countdown unless you keep them.

UPDATES

Updates

NebulaCoop checks its GitHub releases for updates. The SYSTEM page has Check for updates, and Check at start turns the startup check off. Updates and uninstalling keep your saves and settings.

  • Choose Update. NebulaCoop closes and Setup installs the new version, after checking its signature. Run Setup again to repair, restore the previous version or uninstall.

Before a major update, choose Export saves on the GENERAL page.
