COMPATIBILITY

Supported mods

.luma mods, .lumacoop co-op mods, Riivolution packs, disc file replacements, Dolphin texture packs and replacement movies.

Wii code patches cannot run in a native game, and NebulaCoop lists them at import. LumaLink Coop converts a Wii mod to a .luma or .lumacoop file and lists what it cannot use.

IMPORT

Installation

  1. 01

    Open Mods

    Open Options, then the MODS page. It imports and removes mods.

  2. 02

    Import

    Choose Import file or Import folder, or drop the mod on the game window. Archives can be .zip, .7z, .rar or .tar, without a password.

  3. 03

    Pick them for the room

    When you host, choose the room’s mods on the Host page. When two mods change the same file, the higher one wins.

  4. 04

    Play

    Choose the mod’s options, then host. Players who join get the room’s mods.

IN A ROOM

Mods in a room

Mods are the room’s: the host picks them, and joiners download any they don’t have from the host. The mods are checked as each player joins, so everyone plays the same game.

Co-op mods are packed as .lumacoop. They can see who is in the room, add characters and set players’ colours. Plain Nebula refuses them. NebulaCoop comes with two built-in mods:

  • Personal Star Counter, from sm64coopdx: each player’s stars this room and all time. Off by default; the host turns it on.
  • Character Movesets: Luigi’s own moves from Super Mario Galaxy. Off by default, so every character plays like Mario.

TEXTURES & MOVIES

Texture packs and movies

Dolphin texture packs use tex1_ file names. Texture packs On loads images as needed; Preload loads all of them at startup and uses more memory.

Replacement movies go in the movies folder, named like the game’s videos (for example PrologueA.mp4), as MP4, MKV or WebM. 4K video needs hardware video decoding.

TROUBLESHOOTING

Troubleshooting

Turn the mods off on the MODS page (on Windows, you can also hold Shift while NebulaCoop starts). If the problem stops, turn the mods on one at a time. Error codes NEB-M01, NEB-M02 and NEB-M03 name the mod or file involved.
