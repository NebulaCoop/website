Saves

Backups, save import and where saves are kept.

BACK UP

Backups

Open Settings, then the GENERAL page, and choose Export saves. Choose where to keep the dated ZIP file.

IMPORT

Save import

  1. 01

    Find your save

    In Dolphin, right-click Super Mario Galaxy and choose Open Wii Save Folder.

  2. 02

    Import in NebulaCoop

    Open Settings, then the GENERAL page. Choose Import saves and select GameData.bin in that folder.

  3. 03

    Replace and restart

    Choose Replace. NebulaCoop moves your current save to a dated backup folder and restarts with the imported one.

Import saves also reads Wii SD card saves (data.bin), Switch saves (GameData.bin), Nebula.sav files and Nebula ZIP backups. Action Replay saves (.wii) cannot be read. To bring over saves from an installed Nebula, NebulaCoop’s first install offers to import them.

SAVE FILES

Save location

  • Windows: %LOCALAPPDATA%\NebulaCoop\saves

The saves you host rooms with are kept there too. Joiners play the host’s save, so their own saves are untouched. Replaced saves move to a saves-backup-<date> folder beside the saves folder, and Saves folder on the GENERAL page opens it.

Export a backup before a major update or a move to another computer.
