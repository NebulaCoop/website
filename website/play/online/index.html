PLAYER GUIDE

Playing online

Host a room, share its code, and play together.

YOUR PLAYERHOSTJOINDIRECTCHATLEAVEHELP
YOUR PLAYER

Set up your player

Open Options, then the PLAYER page, before you host or join.

  • NAME: how other players see you. If someone in the room already has it, the host gives you “NAME (2)”.
  • CHARACTER: Mario, Luigi or a character a running mod adds. You can switch during play.
  • COLOURS: SET picks a whole set, and a row for each part changes one colour.
  • Pop-ups: which corner messages you see when players join, leave, change galaxy, die or get a star.
HOST

Host a room

  1. 01

    Choose Host

    On the main menu, choose Host, then pick a save or create one.

  2. 02

    Pick the network

    Leave NETWORK on NebulaNet to get a room code. Choose Direct to share your address and port instead.

  3. 03

    Pick who can join

    LOBBY Public lists the room for everyone. Friends only keeps it off the list. A password makes joining need it.

  4. 04

    Set the room

    Choose the player count, the mods and the room options, such as Bubble on Death and Player Interaction.

  5. 05

    Share the code

    Choose Host. The room code shows in your chat and on the ONLINE tab of the pause menu.

The world runs on the host’s PC, so the host needs the steadiest connection. The host can change the room options at any time from the ONLINE tab.

JOIN

Join a room

  1. 01

    Choose Join

    On the main menu, choose Join.

  2. 02

    Enter the room

    Type the room code, or the host’s address:port for a direct room. Or pick a room under ROOMS: Public for everyone’s public rooms, Private for the rooms with the password you typed.

  3. 03

    Get the room’s mods

    Mods you don’t have are downloaded from the host. Your own saves are untouched: you play the host’s save.

DIRECT

NebulaNet or Direct

NebulaNet is NebulaCoop’s room-code service. It introduces the players, and then the game data goes between them directly, so nobody has to forward a port.

Direct skips NebulaNet. The host shares their address and port (UDP 7777 by default) and needs that port forwarded, or everyone on the same VPN, such as Tailscale, ZeroTier or Radmin VPN.

CHAT

Chat and commands

Press T to open a chat line and Enter to send it. Hold Tab (keyboard) or Share (controller) for the player list. Commands start with a slash, and Tab completes them.

Everyone

/help and /players

List the commands, and the players with their numbers.

Host and moderators

/kick, /ban and /permban

Remove a player, refuse them while this room is open, or refuse them in every room you host. Each asks first, and /confirm does it.

Host

/moderator

Lets a player kick and ban too, in every room you host.

With Cheats on

/tp, /teleport and /pos

Move yourself to another player, or show where you are. The host and moderators can move anyone.

LEAVE

Leaving a room

Use the pause menu’s Quit. Only the host’s Quit saves the room’s game. When the host leaves, closes the game or loses their connection, everyone goes back to the main menu.

HELP

Can’t connect?

  • Everyone needs the same NebulaCoop version. Update with Setup if the game says yours is too old or too new.
  • Everyone needs a supported disc: RMGE01, RMGP01 or RMGJ01, revision 0.
  • For a friends-only room with a password, type the password exactly.
  • For Direct, check the port is forwarded for UDP and allowed through the host’s firewall, or use a VPN.
  • If a room code stops working, the host may have left. Ask them for the new code.

Still stuck? Ask on the NebulaCoop Discord or see Help.
